# The Daily Compass — Wednesday 18 November 2026

An original square broadsheet front page summing up Wednesday 18 November 2026 in one image: 38 numbered stories across six continents, a lead report from Manila, APEC in Shenzhen, illustrated panels throughout, and a compact world map whose numbered pins match the story numbers.

The page is built as a single self-contained `index.html` (inline CSS and inline SVG line art in black and red on cream paper), rendered at exactly 1024×1024. `main.ts` copies `entry.png` into `$MAKEFUN_OUTPUT_DIR` (default `/output`) and logs its byte size.
